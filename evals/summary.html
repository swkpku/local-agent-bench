How Fast It Feels

property of the box, not the model

Generation runs at ~10.5 tokens/sec — roughly reading speed. A 9B and a 12B both land here, so this is the machine's ceiling, not a single model's. Prompt processing (prefill) is ~14× faster, so tool-heavy turns feel snappy; long prose is where you wait.

A 4-bit 9–12B on the M4 mini

transcript-estimated · llama-server · flash-attn + q8 KV
Prefill (read)~140 tok/s
Decode (write)~10.5 tok/s
Both sampled models (9B Q4, 12B QAT) measured within a hair of these — it's memory-bandwidth bound.

What that buys you

▸ Snappy on extract / query / analyze — short answers, fast tool loops.

▸ Patient on long reports — a 9k-token write-up is ~15 min.

▸ Free + private — nothing leaves the machine; run it all day at $0.

The Comfort Zone

where a 16 GB box lands

If you remember one thing: a Mac-mini-class model is excellent at anything that's really just code or extraction, workable under supervision for multi-step jobs, and genuinely limited where it needs tools it doesn't have or a bigger brain.

Great today

Just ship it

  • Data analytics — it writes & runs the Python.
  • Structured extraction from PDFs, DBs, logs, XML.
  • RAG over your own docs.
  • Scripted web fetch — a known URL or API.
Workable, supervised

Keep a hand on it

  • Multi-file aggregation across dozens of files.
  • 5–8 step coding bursts with per-step approval.
  • Big-data triage via streaming tools (10 GB+).
  • Verify the precise sub-results.
Needs help / bigger

Not yet, locally

  • Open-ended research — give it a real search tool first.
  • Long autonomous loops without checkpoints.
  • Computer-use (drive a browser/OS) — wants ≥32B.
  • Strict output formatting can wobble.
Bottom line

A base 16 GB Mac mini already runs a capable coding/analysis/extraction agent — fast enough, fully private, free. The wins are everywhere a task reduces to writing code or reaching for the right tool. The limits aren't mystery failures; they're missing tools (real search) and model size (long-horizon autonomy, computer-use). Match the task to the box and a Mac mini does real work.
